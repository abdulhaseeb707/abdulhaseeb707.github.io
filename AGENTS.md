# AGENTS.md: rules for working on this repo

This repo is the personal website of **Abdul Haseeb Khan** (Lahore, Pakistan), published at
https://abdulhaseeb707.github.io with GitHub Pages. Read this file before changing anything.

## 1. The website is the source of truth, and it generates the CV

- All content lives in two places:
  - `src/data/profile.yaml`: identity, contact, timeline chapters, education, experience, honours, skills, services, CV-only fields.
  - `src/content/projects/*.md`: the long story of each project.
- The site **and** the CV are built from that data. The CV is the page `src/pages/cv.astro`, printed to
  `dist/Abdul-Haseeb-Khan-CV.pdf` by `scripts/build-cv-pdf.mjs` on every build (locally and in GitHub Actions).
- Never hand-edit or upload a CV PDF. Never put content directly into `.astro` markup. If a fact changes,
  change it in the data and rebuild; the website and the CV update together.
- Every "Download my CV" button points to `/Abdul-Haseeb-Khan-CV.pdf`.

## 2. Voice: first person, storytelling, on a timeline

- Website copy is written in the **first person** ("I", "my"), as a story the reader follows in time order.
- Every timeline chapter answers, in this order: **when and where → what I did → what I learned or what it led to.**
- Plain, specific English. Prefer dates, places, names and numbers over adjectives.
  Short sentences. One idea per paragraph.
- Banned words and phrases: passionate, leverage, spearheaded, cutting-edge, dynamic, synergy, delve,
  results-driven, world-class, game-changer, seamless, robust (outside statistics), "in today's fast-paced world".
- Photo captions are in the first person too ("Here I am at the podium in Krasnoyarsk…").
- **CV copy** is the exception: standard CV style with implied first person and action verbs
  ("Built a linear programming model…"), no "I".

## 3. Truth rules

- Only claim what is confirmed in `profile.yaml` or backed by a file in `public/files/` or `src/assets/`.
- Never invent results, coefficients, numbers, titles, roles or dates. If a project has no files yet, set `draft: true`
  so it is hidden, or label it as planned work.
- Confirmed facts that are easy to get wrong:
  - CGPA is **3.29/4.00**. Not 3.34, and never "First Division".
  - Meezan Bank: **Banking Trainee, 4 Jun – 4 Sep 2026**. It has ended.
  - MPhil Economics, University of the Punjab: **in progress** (2026 – present).
  - IOFS 2025: **Diploma, II degree, in Economics**, laureate of the V International Olympiad on Financial Security.
  - Youth Festival 2026: participant (Entrepreneurship Track, Interactive International Discussion) **and** presenter
    of "Financial Fraud in Pakistan and Losses to GDP".
  - Python is **basic**.
- Private data never ships: date of birth, ID numbers, the festival voucher (`Voucher.pdf`), home address,
  personal finances, family or health details. The phone number appears **only in the CV PDF**, controlled by
  `cv.showPhone` in `profile.yaml`, never on web pages.

## 4. Design rules: premium, editorial, and clearly made by a person

The previous version of this site was generated by another AI tool and looked like it. That look is the thing
to avoid above all else. The model is a well-made printed feature or monograph, not a SaaS landing page.

- **Light theme only.** Warm paper background, ink-navy text, one deep-green accent. No dark mode, no theme toggle.
- Reading text (intro, chapter text, project write-ups) is set in the serif; labels, navigation and buttons in the sans.
- Solid colors only. **No gradients**, glassmorphism, `backdrop-filter`, blur, glow, neon, decorative blobs,
  floating particles, animated or noise backgrounds.
- No drop shadows. Separate things with whitespace and 1px hairline rules.
- **No emoji** anywhere in the UI or copy. Icons only for social/contact links.
- Imagery is the client's real photos and certificates. No stock illustrations, no AI-generated images.
- Do not default to grids of identical cards. Vary rhythm: long-form text, full-bleed photos, margin notes, lists.
- Text is left-aligned with a readable measure (~68 characters). Headings in the serif, body in the sans,
  dates in tabular numerals.
- Motion: only short reveal fades and smooth scroll, all disabled under `prefers-reduced-motion`.
- Palette and type tokens live in `src/styles/tokens.css`. Do not add colors outside the tokens.
- The page must work without JavaScript: chapters expanded, nothing filtered, lightbox links open the file.

## 5. Commands and tooling

| Command | What it does |
|---|---|
| `npm install` | Install dependencies (first time only) |
| `npm run dev` | Local dev server at http://localhost:4321 |
| `npm run build` | Build the site into `dist/` **and** generate `dist/Abdul-Haseeb-Khan-CV.pdf` |
| `npm run preview` | Serve the built `dist/` locally |
| `npm run photos` | One-time: resize full-size photos from `_archive/originals/` into `src/assets/` |

- Requires Node.js (current LTS). The CV step needs Playwright's Chromium: `npx playwright install chromium`.
- Python 3.15 is available through `uv` for helper scripts (`uv run --python 3.15 …`).
- On this Windows machine new tools may not be on PATH in an already-open shell. Refresh it first:
  `$env:Path = "$env:USERPROFILE\.local\bin;" + [Environment]::GetEnvironmentVariable('Path','Machine') + ';' + [Environment]::GetEnvironmentVariable('Path','User')`
- Deploy: push to `main`. `.github/workflows/deploy.yml` builds the site and the CV and publishes to Pages.
- `_archive/` holds the full-size originals and the old site. It is gitignored, so never delete it.
- `incoming/` is where the client drops new files (project data, slides, evidence). Sort them into
  `public/files/` or `src/assets/` and update `profile.yaml`.

## 6. Checklist before shipping

1. `npm run build` passes (the schemas in `src/content.config.ts` validate the data).
2. `dist/Abdul-Haseeb-Khan-CV.pdf` exists, is **2 pages**, and matches the website.
3. Claims check: these must have zero hits in `dist/`: `First Division`, `3.34`, `Voucher`, `Statsmodels`, `Date of birth`.
4. Design check: `src/` has no `gradient`, `backdrop-filter`, `blur(`, `box-shadow`, and no emoji.
5. Look at the homepage at 375px wide: no horizontal scroll, the timeline is readable, and the CV downloads.
